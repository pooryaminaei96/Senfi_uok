# شورای صنفی دانشجویان دانشگاه کردستان

صفحه معرفی اعضای شورای صنفی دانشجویان دانشگاه کردستان

## نحوه استفاده

1. این ریپازیتوری را روی GitHub بسازید و فایل‌ها را آپلود کنید.
2. GitHub Pages را فعال کنید (Settings → Pages → Source: Deploy from a branch → main / root).
3. لینک صفحه را کپی کنید (مثلاً `https://USERNAME.github.io/REPO-NAME/`).
4. با ابزارهایی مثل [qr-code-generator.com](https://www.qr-code-generator.com/) یا [qrcode.tec-it.com](https://qrcode.tec-it.com/) یک QR کد از لینک بسازید.

## فایل‌ها

- `index.html` — صفحه اصلی
- `logo.jpg` — لوگوی شورا
